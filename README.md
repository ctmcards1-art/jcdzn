# J C Designs (jcdzn.com)

One-page site for the web design business, with the portfolio linking to:

- [CMO Swings](https://cmoswings.com)
- [Cole's Sheds](https://www.colessheds.com)
- [MiLB Report](https://milbreport.com)
- [TRSND](https://trsnd.com)

Two pages, `index.html` and `about.html`, share `styles.css`. No build step.

## Before launch

- **Domain:** `CNAME` sets the custom domain to jcdzn.com; the domain's DNS points at GitHub Pages.
- **Activate the contact form:** each inquiry is sent twice through FormSubmit, once to ctmcards1@gmail.com and once to jackcaricofe222@gmail.com. The first submission sends each address its own activation email; both need to click it once before messages are delivered to them.

## Hosting on GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. To use your own domain, add a `CNAME` file containing the domain and point its DNS at GitHub Pages.
